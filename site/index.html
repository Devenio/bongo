Six lanes of chaos

Bongo doesn't read your happy path.

Unit tests check what you thought of. Bongo checks what you didn't. He picks the right lanes for your code and writes real, seeded property-based tests in your own framework: Hypothesis, fast-check, Go fuzzing, proptest, jqwik and more.

🍌

Input chaos

Empty, huge, emoji, right-to-left text, null bytes, NaN, MAX_INT, malformed dates and JSON, and injection-shaped strings.

""‮2⁵³+1Feb 30
🔀

Sequence chaos

Wrong call order, double submit, use-after-close, retry storms. Random operation sequences are checked against a model.

close();close()undo ×99
⚡

Concurrency chaos

Parallel calls, read-modify-write races, cancellation mid-flight, promises resolving in the "wrong" order.

Promise.all ×50abort()
🌪️

Environment chaos

Missing env vars, full disks, flaky or slow networks, clock skew, Turkish locales, timezones with 45-minute offsets.

ENOSPCTZ=+05:45429
🖱️

UI chaos

A seeded Playwright monkey clicks, types, resizes, goes back and goes offline, and catches XSS, uncaught errors and white screens.

dblclickoffline320×568
🌐

API chaos

Wrong methods, malformed bodies, giant payloads, type confusion and prototype pollution. It flags 5xx responses, hangs and leaked stack traces.

{"a":__proto__?limit=1e9

    Runs on every change
    
    A monkey on Claude's shoulder.
    
    
    The plugin ships a skill and a pair of hooks. Claude can't say "done" on new code until Bongo has had a go. Trivial edits get waved through.
    
    
    
      
    Claude edits code
    A tiny hook notes each changed source file. Tests, docs, config and vendored code are ignored.
    
      
    Bongo blocks "done"
    When Claude tries to finish, Bongo blocks the stop once and hands Claude the exact files to check.
    
      
    Quick monkey test
    Recon, properties, seeded chaos, then triage. It's time-boxed to about 5 minutes and every crash is reproduced and shrunk.
    
      
    Bongo Report
    You get a banana score, verified findings with minimal repros, and regression tests for anything fixed.
    
    
    
    
    
      
    BONGO_MODE=gate (default)
    Blocks the stop once per batch of changes. Safe from loops by design.
    
      
    BONGO_MODE=nudge
    Never blocks. Bongo whispers a reminder after the first code edit.
    
      
    BONGO_MODE=off
    Skill only: call Bongo yourself with "monkey test this". Per-project via .bongo.json.

    Built to be trusted
    
    Chaotic monkey. Strict handler.
    
    
    
      
    🔬
    Prove every banana
    Reproduce, shrink, verify against the contract, then classify. This follows agentic property-based testing research, where a reflection step cut false positives. Unverifiable hunches get their own "suspicious" section.
    
      
    🛟
    Safe by default
    Bongo works only on localhost and temp dirs. The scripts refuse remote hosts, the UI monkey avoids "Delete", "Pay" and "Log out", and the HTTP monkey skips DELETE unless you say --reckless.
    
      
    🎲
    Reproducible chaos
    Every generator is seeded. Re-run with the same seed and get the same mayhem. Confirmed bugs become regression tests in your real suite.
    
    
    
  
    

    


    
  
    
    FAQ
    
    Questions, peeled.
    
    
    
      
    Won't this slow Claude down?
    Quick mode is time-boxed to about 5 minutes and covers only the files Claude just changed. Trivial edits like comments, formatting or config get a one-line "nothing to monkey with". If you want zero friction, set BONGO_MODE=nudge or off.
    
      
    Can it loop forever?
    No. The gate fires once per batch of changes. It honors Claude Code's stop_hook_active flag and forgets edits made during Bongo's own run.
    
      
    Which languages?
    Any. Bongo prefers whatever your project already uses: Hypothesis, fast-check, Go native fuzzing, proptest, jqwik, Kotest, FsCheck, Eris and SwiftCheck. Without a library he falls back to a seeded loop. The UI and HTTP monkeys need Node 18+, and the UI one also needs Playwright.
    
      
    Does it work on claude.ai or the API?
    The skill does. Zip skills/monkey-test and upload it under Settings → Capabilities → Skills, or via the Skills API. The automatic "every change" hooks are a Claude Code feature.
    
      
    Can I make Bongo less silly?
    Yes. Say "no persona" or set BONGO_VOICE=off. The report stays the same; it just drops the jokes. Bongo will sulk, privately.
    
      
    Is it free?
    MIT licensed, forever. Bananas welcome: star the repo, add the badge, send a PR with a new chaos trick.
